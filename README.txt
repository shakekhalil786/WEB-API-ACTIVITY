THREE-IN-ONE WEB PROJECT

CONTENTS

1.  combined_web.html A single responsive HTML file containing three
    website sections:
    -   The Royal Feast restaurant website
    -   Personal portfolio website
    -   ABC Engineering College website
2.  combined_web_screenshots.pdf A visual overview of the three website
    designs, one overview page per website.

HOW TO OPEN

1.  Extract the ZIP file.
2.  Open combined_web.html in Chrome, Edge, Firefox, or another modern
    browser.
3.  An internet connection is recommended because the design uses online
    images.
4.  Use the top navigation to jump between the Restaurant, Portfolio,
    and College sections.

HOW TO CUSTOMIZE

-   Replace sample names, course details, faculty names, contact
    details, prices, and opening hours.
-   Replace image URLs with your own images if desired.
-   For the portfolio resume button, put your own PDF in the same folder
    and name it resume.pdf.
-   The reservation form is a front-end demonstration. It does not save
    or send bookings until connected to a server or form service.
-   The college and faculty details are sample content, not official
    institutional information.
-   The skills bars and achievement examples are placeholders; update
    them to match your actual skills and achievements.

TECHNOLOGIES

-   HTML5
-   CSS3
-   CSS Grid and Flexbox
-   Responsive media queries
-   CSS hover transitions and animations
-   No JavaScript is required.
